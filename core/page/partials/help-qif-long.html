• QIF (Balance only and Balance + trade log): the same transactions, including the monthly returns adjustments, as a QIF file per account, starting with an Opening Balance record (the balance just before the first entry), so no separate starting balance or column mapping is needed. Trade lines aren't included (they don't change the balance), and With holdings has no QIF: QIF's bank format can't carry units and prices. QIF has no currency field: import each file into an account of that currency. Dates are YYYY-MM-DD; the name is the payee (P) and the notes the memo (M).
